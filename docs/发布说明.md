# 知·社区网格 · 发布说明

> 本文档按「原问题 → 解法」梳理本系统从单管理员到「超管派单 + 部门处理」的分工演进，以及新增能力。与代码/线上一致。

## 一、需求落地（原问题 → 解法）

### 用户侧

| 原问题 | 解法 |
| --- | --- |
| 内容不详细、位置难定、非家里 GPS 模糊 | 提交表单含楼栋/单元/房间（默认取注册住址，可改），位置随事件入库；后台「社区设置」可设中心+半径，事件按此做范围校验与距离计算；事件详情/后台均展示定位状态。 |
| 老人文字输入困难，需语音/照片 | 新增语音上报（按住说话录音）+ 照片上传（最多 3 张）；录音经腾讯云 ASR 转写 → DeepSeek 归类派单；后台与居民都可回放录音、看转写、看照片。 |
| 需要时间线，不只状态，回复简单 | 新增事件详情与时间线弹窗：完整展示提交/待处理/已受理/处理中/已完成/拒绝/撤销/改派/改类型每一步的时间、操作人、照片；多轮回复（文字+照片），用户端显示「共 N 条回复 + 缩略图」，点开看全部。 |

### 管理员侧

| 原问题 | 解法 |
| --- | --- |
| 需要部门角色，管理员能处理所有 | 引入角色 `super_admin` / `dept` / `resident`；6 大部门（物业/环卫/安保/工程/综合/调解员）。超管只派单不处理；部门只处理本部门工单。后台新增部门账号管理（新建/编辑/删除/改密，删除连密码一起删）。 |
| 处理要有照片留证 | 完成事件强制 ≥1 张留证照片；回复可带照片；后台/用户都能看照片。 |
| AI 归类可能错，需手动调整 | 超管在「待审核」可归类派单（改类型+选部门）；任意工单可改类型（自动重派）或改派部门；部门账号不能用改类型/改派，只能「转回管理」退回超管重新派单（并显示「由XX部门转回 / 由管理员转派」角标）。 |
| 布局：已受理也在最上、找不到要做的、缺「我处理的」 | 后台改为 Tab：待我处理 / 我处理的 / 全部；已受理/处理中/已完成归入对应 Tab；待办置顶；处理卡片默认可折叠摘要，点开展开，避免超长滚动；部门账号隐藏「全部」Tab。 |

## 重点：部门角色（特别关注）

- **职责边界**：超管=派单/改派/归类；部门=受理→开始处理→完成→回复；部门可转回管理（仅「待处理」阶段，受理后不可回）。
- **数据隔离**：部门账号只能看到本部门工单；事件带 `assigned_dept` / `department_name` / `reviewer_dept`；超管看全部。
- **单账号单登录**：同一账号后登录会踢掉先登录。

## 二、新增功能（超出原清单的）

- **事件列表分页**：后台 + 用户端，每页 20 条，上一页/下一页/页码，显示「共 X 条 · 第 Y/Z 页」；轮询保持当前页。
- **日期筛选**：后台事件列表可按 本日/昨日/本周/上周/1个月/3个月/1年内/全部 筛选。
- **SLA 指标**：平均处理时长（首次处理→完成，按部门各自统计，**按自然分钟计算**，不再按上班时段切片）、办结率、颜色告警（≤5 绿 / 5–20 黄 / >20 红）、部门指标表、风险区（重复/超时/积压）、与上周环比；「上班时间」全局可配置（**不参与处理时长计算**）。
- **AI 周报**：7 段物业简报风格（概况/类型分布/热点/风险/上周对比/SLA 达标率/下周建议）；支持部门筛选、自定义起止日期、历史周回看；复制文本/导出 Markdown；生成等待转圈。
- **系统公告模块**：超管后台发布/编辑/删除公告（富文本+生效/到期）；居民登录强制依次阅读未读公告（无关闭叉，读完才放行），已读永久记忆。
- **SQLite 存储层**：新增 `db.py`，建 `announcement_table` / `user_announcement_read` / `report_table`；旧周报 `data/weekly_reports.json` 启动自动迁入。
- **体验修复**：弹窗滚动隔离（只在框内滚）、回复/详情/AI 周报滚动、生成等待信号、录音保留 30 天自动清理、语音自动派单优化（关键词+应急规则快路径）。
