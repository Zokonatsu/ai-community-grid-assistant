### 2. `main.py`（+12 行）
- 导入 `from prometheus_fastapi_instrumentator import Instrumentator, metrics`。
- 在限流 exception handler 之后新增 Prometheus 挂载块：
  `Instrumentator().add(metrics.default()).instrument(app).expose(app, endpoint="/metrics", include_in_schema=False)`。
- 契约要点：/metrics 无鉴权；不参与业务限流（slowapi 仅作用于显式
  `@limiter.limit` 装饰的端点，`RATE_LIMIT_ENABLED` 不影响 /metrics）；
  `include_in_schema=False` 不进 OpenAPI。
- 【技术说明】任务书要点给出的 `Instrumentator().instrument(app).expose(...)`
  链式调用在 8.1.0（及 7.1.0）下**不会**注册默认 HTTP 指标（构造函数
  `instrumentations=[]`，需显式 `.add(metrics.default())`）。为满足冻结契约
  「/metrics 含 http_requests_total 与 http_request_duration_seconds」，按
  官方 8.1.0 API 增加 `.add(metrics.default())`；expose 参数
  （endpoint/include_in_schema）与任务书一致。已用独立脚本实测核对两种写法。
