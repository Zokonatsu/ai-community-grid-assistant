## 一、变更文件清单 + diff 摘要

### 1. `secure_store.py`（+110 行左右）
- `_aad` 新增 `"field"` 域（与 users/sessions 隔离）。
- 新增 `FIELD_PREFIX = "enc:v1:"`、`encrypt_field(value)` / `decrypt_field(value)`：
  - 非空字符串 -> `enc:v1:<base64(nonce||ct||tag)>`（AES-256-GCM，密钥=DATA_ENCRYPTION_KEY，AAD kind=field）；
  - 空串/None 原样返回；`decrypt_field` 以 enc:v1: 开头才解密，否则明文原样（存量兼容）；
  - 解密失败 raise SecureStoreError（与账号数据一致的 fail-fast）。
- 新增加密字段清单常量：`TASK_ENCRYPT_FIELDS`（13 字段，含数值 event_lat/event_lng）、
  `TASK_NUMERIC_FIELDS`、`EVENT_ENCRYPT_FIELDS`（description/address/reply/user_id/lat/lng）。
- 新增 `encrypt_record_fields(record, fields, numeric_fields=())` / `decrypt_record_fields(...)`：
  逐字段加密/解密副本，不修改原 dict（内存保持明文）；数值字段加密前 str()、
  解密后还原 float/None。
