### 4. `receive_agent.py`（+176 行左右）
- 原 `_call_llm_once` 拆分为：
  - `_call_llm_once_impl`：单次真实调用（无重试/熔断，保持原逻辑）；
  - `_is_transient_llm_error(exc)`：仅瞬时类异常（APIConnectionError/APITimeoutError/429/5xx/
    通用 ConnectionError/TimeoutError/OSError）判定；
  - `_call_llm_once`：tenacity 重试包装（运行期读 config，`stop_after_attempt(LLM_RETRY_ATTEMPTS+1)`、
    `wait_exponential(multiplier=LLM_RETRY_BASE_DELAY)` → 默认退避 1s/2s；`reraise=True`；before_sleep 打日志）。
- 新增 `_LLMCircuitBreaker`（线程安全，closed/open/half_open 状态机）与模块实例 `llm_circuit`：
  - 连续失败 >= `LLM_CIRCUIT_THRESHOLD` → open（记录 `_opened_at`）；
  - open 冷却期（`LLM_CIRCUIT_COOLDOWN`）内 `allow_call()`=False；到期自动 half_open（打日志）；
  - half_open 试探成功 → closed（计数清零）；失败 → 立即重新 open。
- `receive_node`：在「步骤2 多轮采样循环之外」检查熔断——open 时直接返回既有降级
  `{"event_type": "API异常", "confidence": "none", ...}`（main 层转「待审核」，不调 LLM）；
  循环结束后 `parsed_results` 非空 → `record_success()`，全失败 → `record_failure()`；状态/计数打日志。
