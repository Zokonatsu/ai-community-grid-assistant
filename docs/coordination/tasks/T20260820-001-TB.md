## 三、冻结契约

### 3.1 越权矩阵（test_security_authorization.py）
- 水平越权（BOLA，API1）：居民 A 用自己 token → `GET /api/events/{B的事件id}`、`POST .../cancel`、`POST .../mark_read` → 必须 403 或 404，且不产生任何副作用（B 事件状态/已读不变）。
- 垂直越权（BFLA，API5）：居民 token → `GET /api/admin/users`、`GET/PUT /api/admin/community`、`POST /api/events/{id}/accept`、`POST /api/events/{id}/reply` → 403。
- BOPLA / 列表隔离（API1/API3）：`GET /api/events` 居民 A 的响应只含 A 自己的事件；任一事件响应不含他人身份证/手机/定位（`event_lat/lng/event_distance_m/user_id_card/user_phone` 仅 admin 可见）。
- role 校验缺失：注册 `role=admin` → 拒绝（精确文案「禁止通过注册创建管理员账号」）；`role` 非法值 → 400/422。
- 断言风格：精确状态码 + 精确 detail 文案（沿用现有 HTTPException 风格）。

### 3.2 八项接口攻防（test_security_authorization.py，逐项 ≥1 用例）
| # | 攻防项 | 映射接口 | 关键断言 |
|---|---|---|---|
| 1 | 对象级授权（BOLA，API1） | /api/events/{id}、cancel、mark_read | 他人事件 403/404 且无副作用 |
| 2 | 功能级授权（BFLA，API5） | /api/admin/*、accept、reply | 居民 403 |
| 3 | 认证与会话失效（API2） | /api/auth/*、/api/events | 无 token/伪造 token/过期 token/登出后复用/缺 Bearer → 401 |
| 4 | 批量越权 / 过度数据暴露 | /api/events（列表）、/api/admin/users | 居民列表仅自己；响应字段裁剪（不含他人身份证/手机/定位） |
| 5 | 资源限制（API4） | POST /api/events、/api/auth/register、reply | 超长 description(>500)/用户名/回复 → 422/400 拒绝；大请求不导致 500（不压测，现状无限流以注释记录） |
| 6 | 安全配置（API8） | 错误响应、默认凭据、CORS | 错误 detail 不含堆栈/路径/密钥；默认 admin/admin123456 存在性显式断言（风险基线，注释标注待改密） |
| 7 | 注入与不安全消费（API10） | 事件/回复内容、LLM 输出 | HTML/脚本内容后端原样存储不执行；LLM 返回坏 JSON/空/字段缺失 → 降级（待审核/处理失败），不把内部异常透传 |
| 8 | 资产盘点（API9） | app.routes vs INTERFACE.md | 遍历已注册路由，比对文档化接口清单，报告未文档化/废弃接口（不阻塞，输出清单） |

### 3.3 四类断链（test_chain_breaks.py，各 ≥1 用例）
- 检索未命中：明显无效输入（问候/闲聊/宠物死亡）→ `event_type="无效输入"`/已拒绝，不生成工单。
- 工具调用失败：mock receive/dispatch/record 抛异常 → `_process_event` 异常分支置「处理失败」并落盘；不存在「表面成功、无工单」。
- 超时无降级：mock 语义校验超时（50s）→ 降级「待审核」；后台处理超时（60s）→ 「处理超时」（与既有 test_semantic_timeout 去重，只补其未覆盖的 dispatch/record 抛错与坏返回路径）。
- 错误结果直接展示：LLM 返回坏 JSON/空 result/缺字段 → 降级路径生效；事件/回复中 `error` 字段不含内部异常/堆栈/密钥。

### 3.4 造错有效性（test_mutation_effectiveness.py，≥4 类守卫）
- 方式：对被测守卫注入缺陷变体（monkeypatch 模块级引用，如取消 role 校验/归属校验/超时降级/转义），运行对应原用例并断言其变红（`pytest.raises(AssertionError)` 包裹或等价）；每个 mutation 独立测试函数隔离，不污染其它用例。
- 输出：报告「mutation 总数 / 被捕获数 / 未捕获清单（指向缺失或无效用例）」；未捕获项必须给出说明或补用例。

### 3.5 覆盖率（pytest-cov）

- 目标：核心模块语句覆盖率 ≥80%（branch 覆盖率作为附加参考）；main.py 中需真实 LLM/网络的分支用 mock 覆盖。
